LifeCare Health System

Documentação da Solução de Banco de Dados Relacional

1. Domínio do Banco de Dados

O projeto foi desenvolvido para o domínio de Gestão Hospitalar e Atendimento Médico.

2. Contextualização e Problema

A clínica LifeCare operava utilizando planilhas eletrônicas e anotações físicas. Essa rotina gerava:

  • Redundância e dados inconsistentes de pacientes e consultas.
  • Falta de integridade referencial.
  • Riscos de segurança e ausência de controle de acesso.
  • Dificuldade para extrair métricas de faturamento e produtividade.

3. Proposta de Melhoria

Implementação de um SGBD Relacional (MySQL / PostgreSQL) centralizado, garantindo integridade de dados por chaves estrangeiras, prevenção de horários duplicados e geração otimizada de relatórios.

4. Formas Normais Aplicadas

1FN

Atributos atômicos. Telefone e e-mail separados sem listas multivaloradas no mesmo campo.

2FN

Dependência funcional total da chave primária. Na tabela Consultas_Exames, o resultado depende de ambas as chaves compostas.

3FN

Eliminação de dependências transitivas. A tabela Especialidades foi criada de forma independente da tabela Medicos.

4FN

Remoção de dependências multivaloradas independentes, isolando o histórico de exames da tabela principal de consultas.

5. Arquitetura e Cloud Hosting

O banco de dados foi configurado e hospedado em nuvem na plataforma Aiven / Azure, permitindo conexão remota via SSL, rotinas automáticas de backup e alta disponibilidade.
